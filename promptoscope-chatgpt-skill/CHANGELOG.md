# Changelog

## [1.0.0] — 2026-09-26

Première version distribuable de Promptoscope comme Skill ChatGPT autonome :

- analyse des images jointes avec la vision native de ChatGPT ;
- recette visuelle dans la langue de la conversation et prompt de génération en anglais ;
- conservation du schéma JSON Promptoscope v1.0 à 13 clés ;
- méthode d’analyse, règles de prudence et cas de test documentés ;
- aucun appel Gemini, aucune API ou clé externe, aucun backend, serveur MCP ou quota Promptoscope.
