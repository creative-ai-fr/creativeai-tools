# Resolve conflicts for an audit

Start from the competing profile items and their original source evidence. Do not invent a compromise rule.

1. **Applicability:** determine which statements actually cover this market, channel, format, audience, product, and campaign. A mismatch in scope can remove a rule from this audit, but unknown scope cannot.
2. **Source standing:** check whether each source is approved, signed, published, draft, owner-unknown, or otherwise limited. A draft with no approval or authority evidence does not displace an approved rule just because it is newer or more specific. Mention a plausible pending change as unresolved context when useful.
3. **Specificity:** among applicable, comparably authoritative statements on the same subject, a clearly scoped campaign/format/channel/market exception can govern that narrower asset while leaving the general direction in force elsewhere. Explain the scope relationship.
4. **Stated precedence:** apply explicit supersession, exception, revision note, or documented source hierarchy where cited.
5. **Date:** when scope and source standing otherwise match, prefer a newer edition only if the sources are clearly part of the same policy series or evidence shows the newer one updates the older one. Date alone is not proof that an unrelated draft overrides an approved guide.
6. **Decision:** if equally applicable directions still compete, report `UNKNOWN — unresolved conflict`, cite both, and ask the accountable owner to decide. Do not treat either direction as a confirmed violation until resolved.

When a more specific permission appears to create an exception to a broader prohibition, cite both and describe the limited resolution instead of hiding the broader rule. `May use` means permitted in that scope; it does not require use.
