# Conflict management while building a profile

Do not merge contradictory statements into a synthetic rule. Keep each statement and source intact, record the affected scope and dates, and add a conflict entry.

## Resolution sequence

1. **Applicability:** Exclude a statement only when the source clearly does not cover the asset's market, channel, format, audience, product, or campaign. Unknown scope is not proof of inapplicability.
2. **Source standing:** Record whether each source is approved, signed, published, draft, owner-unknown, or otherwise limited. An unapproved or owner-unknown draft does not displace an approved rule merely because it is newer or more specific. If it plausibly signals a pending change, record that uncertainty for review.
3. **Specificity:** Among applicable, comparably authoritative statements on the same subject, a rule for the exact campaign/format/channel/market can govern that narrower scope over a broad rule when it is clearly an exception or localized instruction. Keep the broad rule for other scopes.
4. **Stated precedence:** Honor an explicit supersession, exception, revision note, or documented source hierarchy. Quote or cite the evidence for that relationship.
5. **Date:** If scope and source standing are otherwise comparable, a newer dated edition may govern when sources are clearly versions of the same policy series or the newer text clearly updates the older one. A newer timestamp alone does not silently override a final policy with an unrelated draft, an unknown owner, or a different scope.
6. **Unresolved:** If competing applicable directions remain and the evidence does not establish precedence, record `UNRESOLVED`. Preserve both, cite both, describe the decision needed, and mark the affected profile item `UNKNOWN` for enforcement.

The profile may state a likely interpretation separately, but must label it provisional and must not represent it as resolved policy. Request validation from the accountable owner when useful.
