# Changelog

## [1.5.0] — 2026-10-07

- création du Skill séparé `promptoscope-camera-variants` ;
- conservation byte-à-byte de l’analyse Promptoscope source lorsqu’elle est fournie ;
- sidecars JSON séparés pour l’azimut, l’élévation et la distance ;
- valeurs de caméra bornées et validées par schéma ;
- activation limitée aux demandes explicites de changement de point de vue ;
- aucun serveur MCP, backend, appel Gemini, clé API ou quota Promptoscope.
